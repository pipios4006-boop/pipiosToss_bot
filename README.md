⚖️ **2. 부자 되기 (`Getting Wealthy`) vs 부 지키기 (`Staying Wealthy`) : 바벨 별도 수익금고와 보존선 절대 사수**
  🔸 모건 하우절은 돈을 버는 데는 낙관주의가 필요하지만, 돈을 지키는 데는 단기적 편집증이 결합된 **바벨형 태도** 가 필요하다고 역설합니다. 토스 스나이퍼는 인류의 기술 우상향을 믿는 **순수 롱 `SOXL`** 로 부를 일구되, **바벨 모드 (`BARBELL_60_30_10`)** 를 통해 `SGOV 30%` + `보호현금 10% ~ 40%` 방어막을 세우고 채굴한 모든 세후 순흑자를 **별도 수익금고 (`vaulted_profit_locked_usd`)** 에 영구 격리하며 (`Case 94, 102, 104`), 실전 암살자 출구에서도 스스로 잠근 익절 보존선 (`+1.00% ➔ +1.25%`) 아래로는 단 `1센트` 도 지정가를 내리지 않도록 물리적 하한선을 잠갔습니다 (`Case 107`).
