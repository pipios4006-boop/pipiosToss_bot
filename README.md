# ⚔️ 토스 암살자 (Toss Assassin aVWAP) 시스템 공식 매뉴얼 v32.0

## 📌 1. 시스템 개요: 추세추종의 끝판왕 '토스 암살자'

🔹 시스템 정체성: '토스 암살자'는 미국 증시의 대표 3배 레버리지 반도체 페어인 SOXL(Bull)과 SOXS(Bear)만을 전담 요격하는 초정밀 듀얼 aVWAP(세션 누적 거래량 가중 평균 가격) 순수 돌파/추종 무인 자동매매 퀀트 머신입니다.  
🔹 설계 철학: 인간의 공포와 탐욕, 모니터링 피로도를 전면 배제하고, 수학적으로 입증된 당일 세션 기관 수급선(VWAP) 상향 돌파 시점에만 최우선 매도호가를 스윕하여 낚아챈 뒤 기계적 익절 덫을 즉시 토스증권 클라우드 서버에 심어놓고 퇴근하는 '원샷 원킬' 제로-오버나잇(Zero-Overnight) 방어형 시스템입니다.  
🔹 하이브리드 요격망: 봇 자체의 알고리즘에 의한 자동 매수뿐만 아니라, 운용자가 시장 기회를 포착하여 수동으로 매수한 물량까지 1.5초 이내에 감지하여 즉각 암살자의 익절 덫을 씌워 완벽 통제합니다.

## 🏛️ 2. 핵심 퀀트 매매 알고리즘 (순수 돌파/추종)

### 💡 세션별 독립 aVWAP 동적 연산

🔸 전일 종가의 영향을 100% 배제하고, SOXL과 SOXS 각각 당일의 순수 거래대금/거래량을 기반으로 aVWAP을 세션별로 분리하여 독립 추적합니다.

### 💡 마이크로 휩소(Micro-Whipsaw) 및 듀얼 동시 진입 원천 차단망

🔸 절대 타임쉴드 (04:00 ~ 04:06 EST): 프리장 개장 직후 7분간은 시세 펌핑 및 극심한 노이즈가 발생하므로 어떠한 돌파가 발생하더라도 매수 틱이 누적되지 않도록 원자적으로 0점 처리하여 강제 증발시킵니다.  
🔸 동적 타임쉴드 (04:07 ~ 04:29 EST): 거래량 공백 및 기관 노이즈(휩소) 구간으로 규정하여 40틱(약 60초) 연속 상회를 요구합니다.  
🔸 동적 완화 (04:30 EST 이후): 유동성이 확보되는 04:30 EST부터는 4틱(6초) 연속 확증으로 동적 완화(Downgrade)하여 시장가 요격을 격발합니다. 단 1틱이라도 하회하면 누적기는 원자적 0점으로 즉시 증발합니다.  
🔸 180초 교차 타임쉴드: 선행 종목이 매수 진입한 직후 발생할 수 있는 극심한 방향성 전환(마이크로 휩소) 시, 반대 종목이 곧바로 매수되어 양방향 포지션에 물리는 사고를 방어하기 위해 선행 종목 진입 후 180초(3분) 동안은 반대 종목의 진입을 원자적으로 락온(차단)합니다.

### 💡 시장가 요격 및 진입 타임라인 락온 (Limit-Trap 방어)

🔸 주가가 VWAP 아래에 있을 때 얕은 지정가(LIMIT) 매수 주문을 까는 것을 원천 차단합니다. 조건 충족 즉시 호가창의 최우선 매도 1호가로 지정가 매수 API를 발사하여 100% 즉각 체결을 달성합니다.  
🔸 신규 매수는 오직 1세션 프리장(04:07~09:29 EST) 단독 진입(PRE_ONLY)으로 100% 락온되며, 정규장 개장 시 신규 매수 권한은 영구 소각됩니다.  

## 🎯 3. 기계적 고정 타점 익절 시스템 (Fixed Take-Profit Engine)

암살자의 익절 덫은 3단 하향망 논리를 전면 폐기하고, 오직 +1.0% 단일 하드 락온 타점 시스템으로 가동되어 변동성에 기계적으로 대응합니다.

### ⚔️ 단일 고정 덫 장전 (+1.0% 하드 락온)

🔸 자동 돌파 요격이든 사용자 수동 개입이든 불문하고, 종목의 매수 체결(잔고 발생)이 확인되는 즉시 보유 물량 전체에 대해 평균 단가 * 1.01 (+1.0%) (소수점 둘째 자리 올림) 고정 익절가를 토스증권 조건주문 API 서버단에 위임합니다.  
🔸 조건주문의 만료일(expireDate)은 호출일 기준 30일 뒤로 넉넉히 세팅되어 봇의 메모리 증발과 무관하게 서버에서 100% 익절 감시를 수행합니다.

### ⚔️ 수동 매수 개입 원자적 식별 및 통제 (Manual Entry Mutex)

🔸 사용자가 봇 가동 중 수동으로 매수하여 잔고가 발생한 상황을 1.5초 이내에 원자적으로 식별(buy_order_id 결측)하여 포착 즉시 평단가 대비 +1.0% 익절 덫을 강제 장전합니다.  
🔸 덫 장전과 동시에 당일 자동 봇의 신규 진입 권한을 100% 영구 소각(Mutex Lock)하여 자동/수동 로직 충돌 및 유령 잔고(Naked Shares)를 완벽히 방어합니다.

### ⚔️ 배타적 단독 진입망 (Mutex Trend Follower)

🔸 선행 종목이 당일 진입 이력(buy_order_id 생성, 잔고 보유, 또는 익절 퇴근)을 남긴 즉시 반대편 종목의 매수 진입(틱 누적)을 100% 영구 무효화하여 하루에 오직 시장을 주도하는 단일 방향의 1개 종목만 진입할 수 있도록 원자적 봉쇄를 가동합니다.

###  🛠️ 명령어 상세 가이드

👉 **/start** : 관제탑 메인 메뉴 및 스케줄러를 모바일 최적화 단일 라인으로 즉시 렌더링합니다.  
👉 **/avwap** : 트레이딩 레이더 관제탑. SOXL/SOXS 현재가, 5일 평균 진폭(5MA) 데이터를 기반으로 연산된 당일 예상 밴드 및 팩트 데이터 분리 표출, 진입 단계(PRE대기, 절대쉴드, 동적쉴드, 보유(+1.0%), 타격완료 등) 팩트를 실시간 표출합니다.  
👉 **/sync** : 통합 지시서. 토스증권 원장 데이터(보유 수량, 팩트 평단가, 금일 세션 통합 절대 고가/저가, 실시간 평가 손익(USD/KRW))를 동기화하여 출력합니다.  
👉 **/settlement** : 전술 제어반. 종목별 봇 가동 스위치(🟢 ON / 🔴 OFF) 토글 및 투입 달러 예산(Budget)을 인라인 버튼으로 실시간 변경·통제합니다. 오버나이트 토글 기능은 전면 소각되었습니다.  
👉 **/reset** : 긴급 소각. 2단계 락다운을 거쳐 SOXL, SOXS 로컬 장부(평단가, 덫 위치, 락 플래그)를 원자적으로 0점 초기화(듀얼 장부 동시 원자적 소각)합니다.  
👉 **/update** : 깃허브 메인 브랜치의 최신 코드를 다운로드, 백그라운드 파이썬 컴파일 검증 후 구글 클라우드 서버 프로세스를 강제 하드 킬(os._exit(0))하여 무중단 업데이트를 집행합니다.

## ⚠️ 6. 운용자 절대 주의사항 (오버나이트 통제 철칙)

🚨 **봇 가동 중 오버나이트 불가 (Zero-Overnight 철칙)**
🔹 암살자는 100% 데이 트레이딩 머신입니다. 통합 제어반(/settlement)에서 봇이 [🟢 ON] 상태로 방치되어 있다면, 15:59 EST에 예외 없이 기계적 MOC 융단폭격 청산이 격발됩니다.

🚨 **수동 오버나이트 통제 (Bot OFF)**
🔹 특정 종목을 청산하지 않고 내일로 홀딩하고 싶다면, 시스템 내 오버나이트 변수는 소각되었으므로 반드시 15:59 EST 이전에 /settlement 메뉴에서 해당 종목의 전술 가동 스위치를 [🔴 OFF]로 변경하십시오.  
🔹 봇이 정지되면 15:59 MOC 강제 덤핑 루프도 완전히 셧다운되며, 기존 토스증권 서버에 걸어둔 30일짜리 익절 조건주문 덫만 그대로 살아있는 상태로 안전한 수동 오버나이트가 완성됩니다.  
🔹 사용자가 봇 가동을 OFF한 상태에서 수동으로 전량 매도하여 잔고가 0주가 되면, 시스템은 이를 '수동 매도 청산(is_manual_exit)'으로 원자적 식별하여 명확히 타전하고 허위 익절 알림을 100% 차단합니다.

## 🥷 7. 심층 분석: '숨겨진 암살자의 덫' - 조건주문(Conditional Order)

"왜 봇이 매수를 했는데 토스증권 호가창이나 일반 미체결 내역에 매도 주문이 보이지 않나요?"  
🔹 **지정가(LIMIT) 일반 주문의 한계** : 거래소 오더북에 즉각 노출되며, 주식이 '주문 중'으로 묶입니다.  
🔹 **토스증권 조건주문(SINGLE Type)의 실체**: 봇이 발사하는 익절 덫은 거래소가 아닌 토스증권 중앙 서버 메모리단에 잠복하는 비공개 트리거(POST /api/v1/conditional-orders)입니다.  
🔹 **작동 원리** : 목표 감시가(triggerPrice)에 도달하기 전까지는 절대 호가창에 노출되지 않으며, 사정거리에 도달하는 0.001초의 찰나에 토스 서버가 직접 방아쇠를 당겨 거래소에 일반 매도 주문을 실체화합니다.  
🔹 **확인 경로** : 암살자가 장전한 덫의 실체는 토스증권 앱의 일반 미체결 탭이 아닌, [주식 주문 관리] ➡️ [조건주문(자동감시주문)] 전용 탭의 [감시 중] 리스트에서만 확인할 수 있습니다. 봇은 만료일(expireDate)을 30일로 세팅하여 서버에 이식합니다.
