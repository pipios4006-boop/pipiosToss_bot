⚖️ **2. 부자 되기 (`Getting Wealthy`) vs 부 지키기 (`Staying Wealthy`) : 바벨 60/30/10과 별도 수익금고**  
  🔸 모건 하우절은 돈을 버는 데는 낙관주의가 필요하지만, 돈을 지키는 데는 단기적 편집증이 결합된 **바벨형 태도** 가 필요하다고 역설합니다. 아무리 큰 숫자라도 중간에 `0` 을 곱하면 전체 결과가 `0` 이 되기 때문입니다. 토스 스나이퍼는 인류의 기술 우상향을 믿는 **순수 롱 `SOXL`** 로 부를 일구되 (`SOXS` 영구 차단), **바벨 모드 (`BARBELL_60_30_10`)** 를 통해 `SGOV 30%` + `대기현금 10%` 방어막을 세우고 채굴한 모든 세후 실현수익을 **별도 수익금고 (`vaulted_profit_locked_usd`)** 에 영구 격리합니다. 어제 확정 지은 승리의 전리품을 오늘의 폭락장이 절대 빼앗아 갈 수 없도록 회계 방화벽 (`Case 94, Case 104`)을 세운 설계입니다.  
  
🛡️ **3. 오차 범위 (`Room for Error`) : 바닥을 예언하는 대신 대폭락장 활주로를 깔다**  
  🔸 레버리지 투자자가 파멸하는 진짜 원인은 낮은 기대수익률이 아니라, 예상보다 깊은 조정장에서 현금이 말라 회복장이 오기 전에 퇴출당하기 때문입니다. 토스 스나이퍼는 저점을 예측하는 대신 `8%` 정량 분할, 최고 도달 회차 기억 기반 4단 와이드 단차 잠금 (`-1.0% ➔ -5.5%`), `구 1층` 방패를 살려두는 `L2+L7` 중간합병 (`2022년` 폭락장 탈출 `-275영업일` 단축), 서브 `4회분` 상한 캡, 바벨 `100%` 차액 `Top-Up` 4단계 수혈 워터폴 (`Case 87, 88, 100`)이라는 다중 **안전마진 (오차 범위)** 으로 `-90%` 급 블랙 스완 앞에서도 부러지지 않는 활주로를 확보합니다.

  🔸 복리 수식 `P * (1 + r)^t` 에서 자산을 폭발시키는 변수는 무리한 수익률 `r` 이 아니라 중단 없는 지속 시간 `t` 입니다. 차가운 수학적 최적해라도 운용자가 고통스러워 중간에 봇을 꺼버리면 수익률은 그날로 끝납니다. 삶의 국면에 따라 공격적 증식 (`📈 복리`) ➔ 매월 현금흐름 체감 (`💵 단리`) ➔ 안정적 금고 적립 (`⚖️ 바벨`)으로 언제든 기어를 바꿀 수 있는 **3단 모드 순환 (`Case 91`)** 과, 에어포켓에서 허공 주문으로 슬롯을 가두는 대신 쿨하게 놓아주고 재점화를 노리는 **용서 릴리스 (`Case 99`)** 는 운용자가 밤잠을 설치지 않고 수년간 시스템을 켜둘 수 있게 만드는 지속 가능성의 장치입니다.
