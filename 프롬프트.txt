⚠️ 절대 준수 규칙 (Formatting & Coding Rules)

🏛️ 방탄 아키텍처 5대 절대 헌법
🚨 제1헌법 동기 I/O 비동기 격리 및 중앙 통제 (GlobalThrottle) : 모든 파일 읽기/쓰기(open, json.load/dump)는 예외 없이 asyncio.to_thread로 백그라운드 스레드에 밀어내고 타임아웃(wait_for) 족쇄를 채워라. 다중 API 동시 타격(gather) 시에도 반드시 개별 태스크 내에서 중앙 통제소 GlobalThrottle.wait_api_sync()를 호출하여 Rate Limits Group을 통제하고 백오프하라.
🚨 제2헌법 단일 책임 원칙과 중복 코드 소각 : 하나의 파일 내에 동일한 함수명이 중복 선언되는 프랑켄슈타인 덮어쓰기 사고를 절대 금지한다. 정적 분석기의 관점으로 사용되지 않는 변수, 데드코드, 낡은 로직은 발견 즉시 영구 소각하라.
🚨 제3헌법 타임존 단일 소스 락온 (EST 100%) : 시스템의 모든 논리 시계열 및 토스 달력 API 쿼리 파라미터는 오직 미국 동부 시간(ZoneInfo('America/New_York'))으로만 100% 락온한다. KST는 텔레그램 UI 렌더링 및 응답 파싱 용도로만 철저히 격리하라.
🚨 제4헌법 예측 가능한 멱등성 및 원자적 쓰기 : 장부 및 상태 캐시 파일 보존 시 반드시 임시 파일 생성 후 덮어쓰는 원자적 쓰기(Atomic Write)를 강제하라. 토스증권 주문 전송 시 최대 36자의 멱등키(clientOrderId)를 주입하여 중복 타격을 원천 차단하라.
🚨 제5헌법 엣지 타임라인 Fail-Safe 구조화 : 장마감 직전 격발되는 로직은 달력 API 지연에 대비해 반드시 안전 폴백(Fail-Open) 경로를 하드코딩하라.

⚔️ 토스 주문하기 (HA 암살자) 핵심 공식
🔹 기초 데이터 : 토스 1분봉 기반 3분봉 하이킨 아시(Heikin-Ashi) 캔들. Repainting 방어를 위해 완전히 닫힌(Closed) 직전 2개 캔들만 팩트 검증에 사용한다. 추가로 100% 벡터화된 EMA 10, EMA 20 지수이동평균선을 로컬에서 섀도우 렌더링하여 거시 장세를 판별한다.
🔹 주문 규격 락온 (합성 시장가 전술) : 토스증권 미국 주식 MARKET 주문 제약을 우회하기 위해, 타격 직전 호가장부(orderbook)를 스캔하여 지정가(orderType: "LIMIT")로 꽂아 넣는다. 1회 타격 수량은 사용자가 관제탑에서 설정한 '목표 수량(내림 정수형)' 100%로 락온한다. (기존 Rule 4 하락장 동적 캡핑 방어막 전면 소각)
🔹 매수 타점 (0주 상태 락온 & 상승장 필터) :
🔸 진입 조건 : 잔고 0주 상태에서 완전히 닫힌 직전 2개 캔들을 검증하여 아래 '거시 장세'와 '캔들 패턴'을 모두 충족.
 * 거시 장세 필터 (Up-Trend) : 3분봉 기준 단기 이평선(EMA 10) > 중기 이평선(EMA 20) 정배열 상태 (하락장 및 횡보장 가짜 반등 100% 컷오프).
 * 캔들 패턴 (Track 1 또는 Track 2 충족, 아래꼬리 진공 톨러런스: (HA_Open - HA_Low) / HA_Open < 0.0005) :
   - Track 1 (진성 1봉 단독) : 직전 캔들 양봉 AND 아래꼬리 진공 (몸통 크기 제한 없음).
   - Track 2 (2봉 연속 추세) : 전전 캔들 양봉 AND 직전 캔들 양봉.
   🔸 타점 스캔 : 호가창 매도 1호가(ask_1_price) 추출 (빈 배열 시 런타임 방어 단락 평가).
   🔸 자본 잠김 검증 : usd_bp < ask_1_price * 목표 수량 * 1.03 (지정가 3% 증거금 버퍼) 시 타점 소각.
   🔸 타격 및 기록 : 멱등키(HABUY_타임스탬프)로 지정가(LIMIT) 목표 수량 100% 매수. 체결 직후 ha_state.json 장부에 ask_1_price와 target_qty 2개 파라미터만 원자적 쓰기 락온.
   🔹 매도 타점 (1주 이상 보유 & 절대 이격도 0.2% 검증) :
   🔸 진입 조건 : 잔고 1주 이상 및 직전 3분봉 2개 연속 음봉 (HA_Close < HA_Open).
   🔸 횡보장 휩쏘 방어 : 실시간 현재가(current_price) 기준 ABS(current_price - last_buy_price) / last_buy_price >= 0.002 검증. 미달 시 타점 소각.
   🔸 타점 스캔 : 호가창 매수 1호가(bid_1_price) 추출.
   🔸 타격 및 기록 : 이격도 통과 시 멱등키(HASELL_타임스탬프)로 지정가(LIMIT) 목표 수량 매도. 직후 장부 0.0 초기화.
   🔹 세션 마감 강제 청산 (Zero-Overnight 방어막) :
   🔸 컷오프 조건 : 해당 세션 마감 120초 전 진입 시.
   🔸 강제 타격 : 캔들/장세/이격도 무관하게, 호가창 매수 1호가(bid_1_price) 지정가(LIMIT)로 보유 수량(정수) 전량 강제 매도 및 장부 초기화.
   🔹 유령 잔고 자가 치유 (Self-Healing) :
   🔸 자동 복원 : 실잔고 존재하나 장부 기록이 0.0일 경우, 매도 검증 전 실시간 현재가를 last_buy_price로 앵커링하여 ZeroDivision 즉사 방어.
